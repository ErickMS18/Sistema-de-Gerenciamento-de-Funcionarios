# Merlin - Sistema de Organização de Funcionários

O **Merlin** é uma aplicação web desenvolvida para auxiliar na **organização e gerenciamento de funcionários de uma ONG**, oferecendo uma interface simples para cadastro, visualização e gerenciamento de usuários.

O projeto foi desenvolvido no **2º período da graduação**, na disciplina de **Programação Web**, com caráter **extensionista**.

Durante o desenvolvimento, a ONG **Crazy Cat Gang** visitou a faculdade e apresentou alguns problemas enfrentados na gestão interna de suas atividades. Um dos desafios identificados foi a **falta de um sistema digital para organizar seus funcionários e colaboradores**.  

A partir dessa necessidade, nosso grupo propôs o desenvolvimento do **Merlin**, um sistema web que centraliza informações dos membros da organização e facilita sua visualização e gerenciamento.

## 📌 Funcionalidades

- 🔐 Sistema de **login**
- 📝 **Cadastro de usuários**
- 👤 **Perfil de usuário**
- 📋 **Listagem de usuários**
- ⚙️ **Configurações de perfil**
- 💬 Sistema de **interações e comentários**
- 🌙 **Modo claro e modo escuro**

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** – Estrutura das páginas  
- **CSS3** – Estilização e layout da interface  
- **JavaScript** – Interações e manipulação do DOM  
- **PHP** – Lógica do backend e processamento de requisições  

> ⚠️ Este projeto **não utiliza banco de dados**, pois foi desenvolvido como um protótipo acadêmico focado na construção da interface e lógica de funcionamento do sistema.

## ⚙️ Como Executar o Projeto

1. Clone o repositório

git clone https://github.com/ErickMS18/Merlin-Sistema-de-Gerenciamento-de-Funcionarios.git

2. Coloque o projeto em um servidor local que suporte PHP, como:

- XAMPP  
- WAMP  
- Laragon  

3. Coloque a pasta do projeto dentro de:

htdocs/

4. Inicie o **Apache**

5. Acesse no navegador:

http://localhost/Merlin-Sistema-de-Gerenciamento-de-Funcionarios
